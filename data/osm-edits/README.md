# 일반 지도 로컬 수정 저장소

앱이 별도 `edits.json`을 원자적으로 저장합니다. 원본 PBF/준비된 SQLite 및 시설 JSON과 다릅니다. 실제 수정 파일은 Git에 추가하지 마세요.

호스트 실행은 OSM_EDITS_DIR(기본 data/osm-edits), Compose는 OSM_EDITS_HOST_DIR → /data/osm-edits 쓰기 가능 bind mount를 사용합니다. 변경 전 백업하고 서버 프로세스가 폴더를 읽고 쓸 권한을 유지하세요. Node 기본 실행과 Compose를 함께 쓰면 동일한 수정 폴더를 지정하고 동시에 쓰는 서버는 하나만 운영하세요. 다중 서버/공유 파일시스템 동시 쓰기는 지원 범위가 아닙니다.

원본 재준비는 이 폴더를 지우지 않습니다. 원본 변경 충돌은 앱의 로컬 수정 내역에서 검토하고 재적용/원본 복원하세요. 읽기 오류는 기존 파일을 보존하고 서버 로그·백업본으로 복구한 뒤 다시 조회합니다. 수정 폴더를 지우면 로컬 변경이 사라지므로 초기화 용도로 삭제하지 마세요.
